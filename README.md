## 📖 简介

《勇闯鳌太线》是一款基于 **UniApp + Vue 3** 开发的文字冒险生存游戏。玩家将扮演不同身份的徒步者，挑战"中国最危险的徒步路线"——鳌太线。

鳌太线是中国十大死亡率最高的户外路线之一，全程约80公里，穿越秦岭山脉最高峰太白山，途经多个3000米以上的高峰。这里天气变幻莫测，每年都有徒步者在此遇难。

在这款游戏中，你需要：

- 🎒 管理有限的物资和装备
- 🌡️ 监控生命、饱食度、理智等多项生存指标
- 🌨️ 应对极端天气和突发事件
- 🌙 在昼夜交替中做出生死抉择
- 🏁 努力抵达终点，活着走出鳌太线

> ⚠️ **温馨提示**：鳌太线全线已于2018年正式封禁，请勿非法穿越。本游戏仅供娱乐与科普，请敬畏自然。

## 🎮 核心玩法

### 1. 生存指标系统

| 指标 | 图标 | 描述 |
|------|------|------|
| **生命值 (HP)** | ❤️ | 核心生存指标，归零即死亡。受失温、受伤、饥饿等影响 |
| **饱食度 (Hunger)** | 🍗 | 随行动消耗，过低会导致生命值持续流失 |
| **理智 (Sanity)** | 🧠 | 受恶劣天气、黑暗、恐怖事件影响。过低会出现幻觉，归零触发精神崩溃死亡 |
| **负重 (Load)** | 🎒 | 影响移动速度和体力消耗（开发中） |

### 2. 理智系统

理智是本游戏的核心机制之一。当理智过低时，玩家会体验到：

- **视觉扭曲**：屏幕出现故障效果、文字乱码
- **幻听效果**：听到心跳声、尖叫声等
- **判断失误**：选择文字可能被扭曲，难以分辨
- **最终结局**：理智归零将触发"精神崩溃"死亡结局

### 3. 环境系统

#### 天气系统

| 天气 | 图标 | 影响 |
|------|------|------|
| 晴朗 | ☀️ | 最佳行进天气，无额外消耗 |
| 多云 | ⛅ | 气温适宜，正常消耗 |
| 大雾 | 🌫️ | 能见度低，消耗+20% |
| 小雪 | 🌨️ | 气温下降，消耗+30%，每回合-1HP |
| 暴风雪 | ⚡❄️ | 极端天气，消耗+80%，每回合-5HP |

#### 昼夜循环

- **白天**：正常视野，可安全行进
- **夜晚**：视野受限，屏幕变暗。无照明设备强行赶路极易受伤且理智大幅下降
- **视野系统**：装备手电筒/头灯可在夜晚获得视野

### 4. 职业系统

开局选择不同的社会身份，体验截然不同的生存之旅：

| 职业 | 图标 | 特点 | 初始装备 |
|------|------|------|----------|
| **大学生** | 🎓 | 精神充沛(理智上限120)，自带手电筒 | 手电筒、压缩饼干×3、矿泉水 |
| **运动员** | 🏃 | 体能怪兽(生命上限130)，但新陈代谢快 | 大量食物和水 |
| **医生** | 🩺 | 随身携带药品，理智坚定(理智上限110) | 云南白药×2、压缩饼干×2、矿泉水 |
| **退伍军人** | 🪖 | 野外生存专家，装备专业登山鞋 | 登山鞋、压缩饼干×3、矿泉水 |

每个职业都有独特的特质(Traits)，解锁特殊选项和能力。

### 5. 物品与装备系统

#### 消耗品

| 物品 | 图标 | 效果 |
|------|------|------|
| 矿泉水 | 💧 | 饱食度+15 |
| 压缩饼干 | 🍪 | 饱食度+25 |
| 云南白药 | 💊 | 生命值+20 |

#### 装备

| 装备 | 槽位 | 效果 |
|------|------|------|
| 冲锋衣 | 身体 | 保暖+15 |
| 登山鞋 | 脚部 | 速度+10 |
| 登山杖 | 手部 | 速度+5 |
| 手电筒 | 头部 | 夜间视野 |

#### 特殊物品

- **停摆的怀表** ⌚：诅咒物品，表针永远停在04:44。携带它会发生什么？

### 6. 随机事件系统

游戏中会触发10+种随机事件，每个事件都有多个选择分支：

- 🧑‍🤝‍🧑 **遇到落难驴友**：分享物资？见死不救？还是尝试救援？
- ⛺ **发现废弃帐篷**：要不要进去搜刮物资？
- ⚡ **突遇暴风雪**：强行突围还是紧急扎营？
- 👮 **遭遇巡山队**：配合执法还是冒险逃跑？
- 💀 **发现遗体**：搜刮遗物还是默哀离开？
- 🦬 **羚牛挡路**：原地等待还是大声驱赶？
- 🎶 **幻听秦腔**：停下来听还是掐醒自己？
- 👟 **装备故障**：登山鞋脱胶了怎么办？
- 💧 **水神赐福**：发现一瓶水，喝掉还是留给后人？
- ⚡ **雷击前兆**：头发竖起来了，快做选择！
- 🐗 **遭遇野兽**：制造噪音还是悄悄绕过？

### 7. 探险手记 (Meta-Progression)

- **死亡不是终点**：系统会自动记录你的探险履历
- **结局收集**：收集所有结局（成功穿越、失温、滑坠、疯癫...）点亮图鉴
- **尝试次数**：记录你向大自然发起的每一次挑战

## 🚀 快速开始

### 环境要求

- Node.js >= 16
- [HBuilderX](https://www.dcloud.io/hbuilderx.html) (推荐) 或 VSCode + UniApp 插件
- 微信开发者工具 (如需编译微信小程序)

### 安装与运行

```bash
# 克隆项目
git clone https://github.com/your-username/Braving_Aotai_Trail.git

# 进入项目目录
cd Braving_Aotai_Trail

# 安装依赖
npm install

# 运行 H5 版本
npm run dev:h5

# 运行微信小程序版本
npm run dev:mp-weixin

# 运行 App 版本
npm run dev:app
```

### 使用 HBuilderX

1. 打开 HBuilderX
2. 导入项目：`文件` -> `导入` -> `从本地目录导入`
3. 运行：`运行` -> `运行到浏览器` / `运行到小程序模拟器` / `运行到手机或模拟器`
